COMO APLICAR NO GITHUB DESKTOP
1. Faça backup da pasta local atual do repositório assotck.
2. Extraia o ZIP completo e copie o conteúdo da pasta assotck para a raiz do clone local, mantendo a estrutura de pastas.
3. Substitua os arquivos da aplicação listados acima. Adicione as três migrações à pasta supabase/migrations.
4. Preserve o arquivo .env local (ele não é distribuído neste pacote), a pasta .git e os valores de Variables do GitHub Actions.
5. Preserve .github/workflows/deploy.yml; o workflow existente do GitHub Pages já está configurado para compilar o projeto e publicar dist/.
6. No GitHub Desktop, confira os arquivos alterados, faça commit e clique em Push origin.
7. Abra GitHub Actions e confirme que build e deploy terminaram com sucesso. Depois atualize o site com Ctrl+Shift+R.
