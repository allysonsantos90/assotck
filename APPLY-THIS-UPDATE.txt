AS KITCHEN STOCK — DASHBOARD & ANALYTICS UPDATE

PACKAGE
This ZIP contains the complete AS Kitchen Stock v2 source tree, including the previous stock, product detail, location detail, supplier detail, purchasing and receiving features, plus the new Dashboard analytics.

APPLY IN GITHUB DESKTOP
1. Back up your existing local repository folder.
2. Extract this ZIP. Copy the contents of the askitchenstock-v2 folder into the root of your local clone of allysonsantos90/assotck, allowing matching files to be replaced.
3. Preserve your local .git folder and your existing .env file. The package contains .env.example, not your private credentials.
4. Review the changes. The new analytics component is src/DashboardAnalytics.tsx and is mounted from src/App.tsx; styles are appended to src/style.css.
5. In the repository folder run: npm install, then npm run build.
6. If the build succeeds, commit the changes and click Push origin.
7. Open GitHub Actions and confirm the GitHub Pages deployment workflow succeeds. Only then refresh the published site.

SUPABASE
No database migration is required for this Dashboard update. Do not rerun any existing migrations included in the source tree against the already-connected Stock project. The dashboard reads existing tables, organization scoping and RLS policies. It does not write stock balances or insert sample transactions.
